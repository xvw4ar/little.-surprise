CYBERPUNK BIRTHDAY WEBSITE

Files:
- index.html
- assets/birthday-song.m4a

To preview:
1. Keep the assets folder beside index.html.
2. Open index.html in a browser.

To publish with GitHub Pages:
1. Upload index.html and the complete assets folder to the root of your repository.
2. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).
3. Save and wait for the Pages link.

The music starts only when the visitor presses Play. The page is responsive and respects reduced-motion settings.
